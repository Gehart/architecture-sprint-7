## Список требований для внешних интеграций

- Соединение только по защищенному соединению
- Передача только ограниченного набора персональных данных или данные будут обезличенные
- Подписание договора о защите персональных данных
- аудит партнеров по действиям по сохранности данных
- авторизация и аутентификация с помощью сертификатов с электронной подписью или OAuth 2.0.
- обязательства по выполнению 152-ФЗ и других требовании законодательства (в частности, по сохранности биометрических данных)
- логирование действий партнера в системе.

Взаимодействие со сторонними системами должно основываться на принципе наименьших привилегий. У систем должен быть максимально ограниченный набор данных.
