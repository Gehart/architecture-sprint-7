| Роль  | Права роли | Группы пользователей |
| --- | --- | --- |
| Название роли, которое отвечает требованиям RBAC в Kubernets. | Укажите права, которые необходимо выдать этой роли. | Выделите группы пользователей в организации, которые нужно связать с этой ролью. |
| developer-view  | Только чтение (get, list, watch) | Разработчики |
| admin | Полный доступ (*) | Администраторы     |


Демонстрация работы:
```sh
mac@gehart-2 ~/a/s/task4 (sprint7)> kubectl auth can-i get pods --as developer-view
yes
mac@gehart-2 ~/a/s/task4 (sprint7)> kubectl auth can-i get pods --as admin
yes
mac@gehart-2 ~/a/s/task4 (sprint7)> kubectl auth can-i delete pods --as developer-view
no
mac@gehart-2 ~/a/s/task4 (sprint7) [1]> kubectl auth can-i delete pods --as adminw
no
mac@gehart-2 ~/a/s/task4 (sprint7) [1]> kubectl auth can-i delete pods --as admin
yes
```
